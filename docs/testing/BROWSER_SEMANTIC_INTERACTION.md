# Public semantic interaction and owner continuation

An ordinary owner request can select `browse_page({retain_session:true,...})`, then use the returned session handle and fresh refs for repeated actions and observations. Omitting the lifecycle option preserves the one-shot page-read path. This is model-facing lifecycle selection, not an owner setup step or a new trial registration. The source is integrated against staging base `44fc58ca14024e571f8c79af4579d2977b932353`, reusing preserved semantic source `7a21a6b6`. Basic deployed page-read evidence does not establish live advanced-browser acceptance.

The existing Cloudflare Playwright driver, current owner runtime and durable host remain the execution path. New public commands are `select(element_ref,value)` and `set_checked(element_ref,checked)`. Native select option/checkbox state is returned with observation refs. Open-shadow controls follow their hosts in trusted native CSS paths; observed writable contenteditable nodes can use the existing type command. Closed roots and cross-frame action refs remain unsupported. Native DOM selectors are never supplied by model arguments.

Snapshot evidence adds Chromium accessibility role/name/value/states and child indexes with no backend node IDs. Real local Chromium showed Playwright body ariaSnapshot exposes password values; the native Accessibility.getFullAXTree masks those values. The new local probe asserts the complete snapshot excludes a synthetic password. No private `_snapshotForAI` dependency or framework switch. The projection and screenshot are reread before publishing; changed evidence invalidates refs. Semantic reads fit the existing action/run/session timeout. Existing 128 KiB durable-checkpoint/PNG caps apply without silent truncation.

Provider `keep_alive` is a ten-minute inactivity timeout, separate from task lifetime. An ordinary session is funded through the actual admitted run deadline plus one owner-reply idle window and a second idle/cleanup allowance. A continuation uses the same original session window and does not extend it. Each action still obeys its current run deadline. No daily allowance or trial refilling is introduced; prior owner charges, lower total ceilings and monthly totals remain binding. Exact-session absence permits duration settlement in the original reservation month; uncertain closure retains the full hold.

The model retains only four recent PNGs; this does not limit browser actions or observations. Pause does not extend authority or provider expiry. Normal owner-turn completion drops request authority while retaining the admitted disposable context; idle POST requests remain blocked. An owner reply explicitly continues the same host session and obtains fresh evidence before actions. An expired/lost session is not silently replaced. Connection loss recreates documents only on an explicit read inside the same funded session; unsent state and old refs are reported lost. Native submits, page sends, file upload, saved sign-in state and Live View remain separate. There is no general observed-condition wait; native locator actionability uses the existing 10-second/run/session bounds.
