# Public semantic interaction and owner continuation

A public browser task can select an observed enabled native option, set a checkbox/radio to an explicit desired state, read the resulting semantic state, pause for owner input at the normal turn boundary, resume the same session, deliver a verified PNG and close the exact provider session. No new provider, lease, credential flow or budget is introduced. The advanced slice is based on PR965 head0896ea3d; its same-policy renewal/diagnostics must land first. Basic served task acceptance remains unverified.

The existing Cloudflare Playwright driver, current owner runtime and durable host remain the execution path. New public commands are `select(element_ref,value)` and `set_checked(element_ref,checked)`. Native select option/checkbox state is returned with observation refs. Open-shadow controls follow their hosts in trusted native CSS paths; observed writable contenteditable nodes can use the existing type command. Closed roots and cross-frame action refs remain unsupported. Native DOM selectors are never supplied by model arguments.

Snapshot evidence adds Chromium accessibility role/name/value/states and child indexes with no backend node IDs. Real local Chromium showed Playwright body ariaSnapshot exposes password values; the native Accessibility.getFullAXTree masks those values. The new local probe asserts the complete snapshot excludes a synthetic password. No private `_snapshotForAI` dependency or framework switch. The projection and screenshot are reread before publishing; changed evidence invalidates refs. Semantic reads fit the existing action/run/session timeout. Existing128KiB durable-checkpoint/PNG caps apply without silent truncation.

Pause does not extend authority or provider expiry. Normal owner-turn completion drops request authority while retaining the admitted disposable context; idle POST requests remain blocked. An owner reply explicitly continues the same host session and obtains fresh evidence before actions. An expired/lost session is not silently replaced. Connection loss recreates documents only on an explicit read inside the same paid session; unsent state and old refs are reported lost. Native submits, page sends, file upload, saved sign-in state and Live View remain separate. There is no general observed-condition wait; native locator actionability uses the existing10second/run/session bounds.

Verification: focused fake tests use the actual ordinary two-argument ownerDO/model tool schema/host/spend/owner workspace, including the question and next owner reply; fake transport is not a live provider claim. The standalone localhost Chromium probe tests native semantics/password exclusion, selects/checkboxes/shadow/editor, idle requests, human changes, loss/recovery and physical cleanup without acquisition. It uses a disposable profile and a synthetic public site; no real account. Exact release head, logs and review receipt belong in PR/handoff.
