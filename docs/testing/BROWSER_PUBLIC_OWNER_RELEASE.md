# Normal staging Cloudflare public read

The ordinary owner host can read an allowed public page using explicit `cloudflare_playwright` when no trial registration exists or it has expired. It reuses the existing Cloudflare public reader, which creates an isolated context, returns page text or typed failure, physically closes the browser and checks absence. A fresh normal read ends its session; registration-backed retained sessions still use their existing host and deadlines. Browserbase remains explicitly selectable and is never an automatic fallback.

Normal browser cost is reserved before acquisition against the existing $5/month owner browser counter and prior common-spend ledgers. Existing retained lower monetary ceilings also apply. The 30s work, 10s cleanup and 10s idle window reserves 1,250 microUSD ($0.00125) for 50 seconds at $0.09/hour, rounded up. After exact physical cleanup is confirmed, that reservation settles to measured elapsed duration; uncertain cleanup or an invalid/over-bound duration keeps the full hold. These are estimated browser-duration charges, not Cloudflare account billing or vendor reconciliation. Account-level peak/rounding charges remain part of the registered test envelope, and historical v1 $2.09 reservations are never repriced or refunded by this change.

New test registrations and declared test ceilings may not exceed the owner-approved $10 total test cap; the browser cap remains $5/month. The old v1 $20 format/default remains readable solely to preserve charges and replay evidence. Actual lower retained ceilings remain binding, including historical ceilings between $10 and $20. Historical registration inspection and already-funded exact-session cleanup use the historical format limit, while new admission uses $10. Reading history grants no new test admission. A valid expired historical descriptor may select the existing fresh normal-read path only after unchanged owner/pin validation. Its effective admission ceiling is the lesser of $10 and actual lower declared or retained ceilings; all old charges still count. Neither the historical descriptor nor its pins/ledgers are rewritten, and removing the descriptor cannot restore an older higher test ceiling. Live or future registrations above $10 remain rejected. Normal reads have no invented lifetime cap, and this implementation adds no ordinary model-turn gate. There is no general per-owner model spending service in source. Parent must establish remaining already approved test allowance before any paid staging attempt.

Authenticated GET `/console/diagnostics/common-runtime-readiness` is read-only and independent of registration expiry. It reports binding/SDK readiness, current/aggregate retained registration reservations, monthly totals and cleanup counts. Missing values and external prior use remain unknown. It does not renew registration, reset counters or invoke SDK/model/provider code. Trial registration status does not define ordinary public provider readiness.

A retained funded browser record with expired/unavailable trial configuration no longer closes an open ordinary model run: it uses the existing ordinary model adapter and run policy. Browser source does not create unlimited inference authority or relax live trial ledger ceilings. Read/act host errors expose fixed safe error classes without exception messages.

The acceptance capsule, run/model-call test gate, SDK retry changes and expiry renewal from the earlier candidate are deferred. No owner-approved expiry extension is inferred. No production, key/grant/cap change, private login, DB operation or live provider call belongs to source validation.

Core merges the trimmed basic head independently of advanced PR966. Parent/operator deploys the exact merged beta head with existing approved staging serving configuration, retaining BROWSER and public egress, and verifies served version and WALDO_RELEASE. The inspected wrapper requires explicit `--env staging`; never use its production default or blindly replace the actual serving profile with source Wrangler defaults. Read the authenticated diagnostic, establish remaining approved allowance, then Core executes the coordinated public task and records useful content and exact physical cleanup. Denial/timeouts/empty text or successful transport alone do not pass.

## Rollback after v2 usage

Once `owner-public-browser-spend:v2` exists, any rollback must retain the v2 reader and capacity checks for normal reads and registration-funded browser/model calls, or disable new normal allocations and any funded path that would ignore v2 charges. Keep v1/v2 ledgers, monthly counters, retained ceilings and replay evidence intact. Do not delete, reset, down-convert or fabricate refunds to make an older release run. In-flight cleanup and settlement still need the v2-capable code; disabling allocation is not permission to abandon a live session.
