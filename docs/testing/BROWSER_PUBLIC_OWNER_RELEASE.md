# Public owner browser release

This slice opens and reads an approved public site, uses observed native non-effect clicks/type/scroll/navigation and tabs, continues the exact owner session, saves a PNG through the existing authenticated owner workspace, and cancels/cleans up the exact provider session. Cloudflare is explicitly selected; Browserbase remains an explicit alternative and is never an automatic paid switch.

The existing staging admission configuration `COMMON_BROWSER_REGISTRATION` is absent by default, and `env.staging.browser` is absent. Both are required for admission. Production never selects the staging host. This PR changes neither deployment setting nor existing caps. Parent owns enabling the exact staging BROWSER binding and reviewed registration after Core merge and paid-test authorization. This slice adds no migration, connector proxy, private custody, saved-login state, Live View, file upload or form-submit implementation. Existing legacy approved submit behavior is unchanged.

POST/PUT/DELETE and native form submission are refused by the public host. Observations are external evidence, not instructions. Every native navigation/tab/field action durably records intent before dispatch, and uncertain outcomes cannot replay. An HTTP acknowledgement is not task completion. The driver retains one disposable context under the original paid session and expiry; detach/eviction loses document state and old references. Recovery creates fresh documents only within that same admitted session and budget, never a replacement allocation. Exact cleanup failures remain visible.

Screenshots contain native PNG bytes and use existing owner workspace quota/custody. Delivery provides an owner-authenticated file/revision URL with verified readback; it never publishes provider credentials or an open screenshot URL. The ordinary ownerDO fake journey exercises read, native typing, reobservation, tabs/continuation, screenshot retrieval and cancel/new-task. Off-state controls cover inbox, day plan, reminders and memory. Source/fakes/CI do not prove live Cloudflare timing or staging CPU latency.

## Address refusal

`That address cannot be opened. Try another source.` is emitted by the PreToolUse egress hook before browser configuration/provider dispatch. Current source staging allowlist is example.com, en.wikipedia.org, github.com, news.ycombinator.com, developer.mozilla.org and heywaldo.in. An unlisted host or forbidden network address is denied; a separate dark host returns an owner-browser unavailable refusal. The requested failing URL is needed to attribute its exact host-level denial. This release does not widen private-network access or alter the list.

## Same-reference renewal and one-owner staging acceptance

The activation follow-up preserves existing paid custody. Automatic `verified_owners` registration may extend `policy.expiresAt` and `spend.validUntil` under the same ref, owner and custody only after every retained browser has confirmed closed/ended cleanup. All other registration fields, prices, billing envelope and caps remain unchanged. Usage, grants, allocation/time counts, monthly totals, model/browser reservations and cleanup issued counts are validated and retained atomically. Old grants and sessions keep their old deadlines. Extending a registration cannot refill exhausted allocation or money capacity, and the unchanged billing-day envelope must still cover the extended window. Manual registrations with an already mismatched retained policy still require explicit reconciliation; this follow-up does not rewrite unaudited manual policies.

An optional `acceptance` capsule in the existing registration binds the paid test to exactly one `doName`, `subject` and `directoryOwnerId`. It supplies `expiresAt`, `maxRuns` (at most 2), `maxModelCalls` (at most 8), and mandatory audited `priorRuns`, `priorModelCalls`, `priorMicrousd`. These are operator receipts, never inferred as zero from absent rows. `priorModelCalls` includes all model requests already made before the gate is attached, including the retained ledger's baseline model calls. `priorMicrousd` is earlier paid cost outside this specific retained spend ledger; that ledger's existing reservations are added separately, including uncertain calls and prepaid cleanup. Audit across all earlier attempts/other policy refs before populating the capsule. Counts cannot be changed after attachment and the test expiry does not extend when registration expiry renews.

The selected owner's first routing request and subsequent reaction, subagent, memory and degradation model calls pass through the same gate before browser allocation. One gate reservation issues at most one HTTP model attempt: SDK retries and the empty-output second request are disabled for this test. Other owners and ordinary browser-off paths preserve their existing behavior. This is a one-owner model-bearing run limit, not an account-wide concurrency service or an inbox-admission counter. Do not run another paid test concurrently. A model override without its registered price is refused. Reconstruction, capsule removal or unavailable binding/SDK cannot restore unmetered calls for the retained selected test. Pre-funded exact-session cleanup remains available after expiry/revocation.

Operator acceptance procedure (staging only):

1. Record exact served Worker commit/version, traffic and redacted binding names. The operator reports `BROWSER` is served; absent source defaults do not establish the live binding state. Read the actual current registration and the selected owner's pinned registration, all spend refs, usage/allocation/time rows, monthly totals, cleanup state and prior paid test receipts. Do not reset, delete, migrate or repair storage to pass preflight.
2. Confirm the already approved remaining cumulative money, model requests, model-bearing runs and browser allocation. Unknown/exhausted allowance blocks a paid test. Confirm unchanged actual billing envelope and public egress target. Use the approved renewed expiry under the same ref; add the exact-owner capsule with audited prior usage. No new grant, key, plan/cap change or private account is involved.
3. Parent/release operator publishes and deploys only after reviewed source, exact-head CI and the serial CI slot clearance. Cold reconstruction builds wrappers from the renewed pin; never reuse old wrappers for a changed policy.
4. Submit the approved owner's public task through the ordinary existing host with explicit `cloudflare_playwright`. Require useful content from an allowed public page plus observed navigation/native action and an owner-accessible PNG when requested. A denied page, timeout, transport connect or empty output is not task completion. Continue explicitly with the returned session handle within its original session deadline; there is no automatic Browserbase fallback.
5. Cancel/expire the exact retained session; inspect provider readback and durable closed/ended cleanup. Re-read all counters to prove consumed counts increased and stayed under the existing cumulative allowance. Record physical model requests (including routing/memory/degradation), provider allocation/session ID, useful page evidence, screenshot receipt and cleanup. Stop on uncertainty; do not grant a replacement allocation or refill counters.

SOURCE and hermetic fake tests cover the renewal/gate. No new live Cloudflare/model call or served staging acceptance is claimed by this follow-up. Private login/storage state, Live View, file selection and page sends remain outside the public slice.
