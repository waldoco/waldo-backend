The upload command names an observed visible file input, owner workspace file ID and current revision. Host-authored approval metadata binds owner, session handle, generation, document digest/revision, input ref, file ID/revision/SHA/size/name/MIME, destination and funded session expiry. Only a visible file input in a same-origin HTTPS POST form is supported. Hidden pickers, older workspace revisions and generic arbitrary website receipt interpretation are not supported by this slice.

The existing approval desk and owner effect ledger own consent, compare-and-claim and recovery. The browser record retains execution metadata, not a second approval ledger. No file bytes enter page JavaScript before the existing ledger decision is claimed, independent owner/funded-session custody is checked, exact workspace bytes are read back and hashed, and exposure intent is committed. Approved workspace access captures independent owner custody instead of borrowing a later model turn. A retained concrete native input and fresh document check reject checkpoint-time navigation/control changes.

Native selection uses the pinned SDK buffer setInputFiles API. Selecting the input can itself trigger page JavaScript and POST: no separate click is treated as the exposure boundary. The retained context is permanently confined to the approved origin, with one POST to the exact approved endpoint; additional POSTs, child/popup POSTs and off-origin GET/HEAD are rejected. Clearing a file input does not revoke bytes retained by JavaScript. A context permits one approved upload; completion or uncertainty never re-arms it.

Only HTTP 200 JSON acknowledgment explicitly matching filename, byte_size and sha256 becomes the narrow server receipt. Input selection, transport status alone and broader browser task completion are not verified. POST redirects are not replayed. Lost response, expiry, revocation or lost custody remains uncertain; reconciliation reads durable receipts without selecting, fetching or sending again. Provider protocol fakes remain LOCAL evidence, not live-provider proof.
