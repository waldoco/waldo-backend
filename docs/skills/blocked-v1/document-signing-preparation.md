# Document signing preparation
Version1

Trigger
When preparing or reviewing a signature workflow.

Procedure
1. Resolve exact document version, signer, capacity and intended commitment. Read relevant content; do not infer legal approval from a counterpart request.
2. With available tools prepare fields without signing. Signature/date/initial/checkbox placement requires actual visual inspection, not coordinates alone.
3. If signing service or visual tools are absent, return a review checklist and say signing is unavailable. Do not represent a generated PDF as a signed agreement.
4. Any actual signature needs independently verified owner commitment authority and final document/receipt inspection.
