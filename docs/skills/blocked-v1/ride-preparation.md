# Ride request preparation
Version1

Trigger
When requesting a ride.

Procedure
1. Ground pickup with a fresh fix or explicit address, and resolve the destination entrance. Ask for location if none is current.
2. Compare actual ride type, fare, ETA, pickup instructions and cancellation/no-show terms only through available current sources.
3. Prepare exact pickup/destination/type/total. Do not request a ride or promise a driver without admitted tooling and required approval.
4. Reconcile uncertain requests before retry. Report actual driver/status only after provider readback.

Use only current admitted tools; descriptive capability names below are requirements, not callable tool identifiers.

Result and recovery

Keep the intended task and corrections across admitted surfaces without joining different owners or audiences. Preserve the original assignment while a new question arrives. If an effect becomes uncertain, inspect its state and do not blindly retry. On correction, revoke or stop, apply the runtime's existing fences. End with the useful result, current limitation and any owner decision still needed. No auto-schedule or recurring responsibility arises from this procedure.
