# Packaging plan: build order with the concierge vision placed (2026-09-24)

The owner's north star, his words: an agent that reasons across health, life and work, connects it all for one person, and closes their open loops - tasks, follow-ups, personal commitments, health goals. This plan places that vision explicitly in the build order.

## What "the concierge" requires, decomposed

1. **Memory that travels with its reasons** - done at the layer level (stated/confirmed/inferred claims); transport (MCP) designed in the minimi deep dive.
2. **Surfaces where the owner already is** - Telegram live; WhatsApp designed + confirmed; console live; dashboard planned.
3. **Actuation** - reminders, calendar, mail, cards, fetch: built, awaiting keys for live proof.
4. **Cross-domain reasoning** - the model connecting a bad night's sleep, a 3pm meeting and a training plan. This is an intelligence-layer capability, gated on model choice and eval cover.
5. **Open-loop closure** - the loop ledger exists; proactive closure is again intelligence-layer.

## The build order

1. **Keys land** (owner's critical path now): Supabase, Google, Brave, Smallest AI, OpenAI all-models, WhatsApp test number. Guide: OWNER_STEP_BY_STEP_SETUP_2026-09-24.md.
2. **Combined live e2e**: one real day on staging with all connections - chat, calendar connect, mail triage, a reminder, a fetch, a card. /e2e checklist all green on live data, not fixtures.
3. **Model pick**: the A/B (nano vs mini vs luna) on the W7 suite + live turns, quality-per-dollar decided on numbers per the token-efficiency brief. This is where concierge-grade reasoning gets its engine - and per the owner's 1:01 worry, nothing context-cutting ships without eval cover.
4. **Eval fixes**: the six W7 findings (dosing, blunt sanitiser, owner-typed emails, whole-web-set drop, hook halted, chat mail tool).
5. **Dashboard phase 1**: the owner watches his agent work; trust through visibility.
6. **Intelligence-layer cycles** (the concierge proper): cross-domain reasoning prompts + memory fetch depth, proactive open-loop closure, morning/evening synthesis. Each cycle ships behind evals. This is where the vision in his 1:01 message becomes product.
7. **WhatsApp channel live** (test number already moving; business verification in parallel) - then the beta packaging moment: one message surface + dashboard + memory that travels.
