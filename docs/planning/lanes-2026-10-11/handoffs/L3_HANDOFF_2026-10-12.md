## 6. Verification and pitfalls

**The wall.** Run it in a bash script, not zsh, because zsh doesn't word-split `$VAR` commands:
```bash
node packages/runtime/scripts/bundle-skills.mjs --check
npx -y pnpm@10.34.4 install --frozen-lockfile
npx -y pnpm@10.34.4 --filter @waldo/dashboard-app build
npx -y pnpm@10.34.4 -r typecheck
npx -y pnpm@10.34.4 verify:node
npx -y pnpm@10.34.4 verify:workers
npx -y pnpm@10.34.4 verify:guards
npx -y pnpm@10.34.4 --filter @waldo/runtime test:scenarios
npx -y pnpm@10.34.4 --filter @waldo/runtime test:owner-ingress
git diff --check
```

**Expected results:**
- `verify:workers` at `21a70277` should run **424** files. A lower count with every test passing means pool runners never started.
- `guard-pgtap` is UNAVAILABLE on macOS; PR CI runs pgTAP.
- **Never run `verify:supabase` locally:** it resets the shared Supabase stack for every lane.

**Pitfalls that caught L3:**
- **`verify:node` chains suites with `&&`.** A contracts failure skips the workspace, browser-fixture and iMessage suites, so rerun all of it after a fix.
- **Vocabulary pins live outside `src/app`.** `contracts/src/runtime/reply-parts.test.ts` pins the approval action list. Grep all of `packages/` before changing an enum.
- **Vitest doesn't typecheck.** A guard can be needed only for `tsc`, so run `pnpm -r typecheck`.
- **`guard-setalarm` covers tests too.** Use `armAlarm`.
- **A single 5000 ms timeout in `dashboard-reconcile-forget` under full-suite load** has been seen. It is logged on #116 (6108277860); reproduce it alone three times before calling it unrelated.
- **Advisor claims need checking.** A suggested code-point cut would have overflowed the UTF-16 limit.
