# Archived Foundation Notes

This directory keeps historical phase handoffs, old build plans, audits, and benchmark reports that
are useful for archaeology but are not active planning entrypoints.

For current work, read:

1. `docs/foundation/CONTRIBUTOR-ONBOARDING.md`
2. `docs/foundation/NEXT-SESSION-PLAN.md`
3. `docs/foundation/HARNESS-RUNTIME-BUILD-PLAN.md`
4. `docs/foundation/LOCAL-DEV-TESTING-PIPELINE.md`

Do not use archived Phase A/B/D notes, slice handoffs, old foundation handovers, or benchmark
reports as the current next-session plan.

Archived reviews and phase reports may mention old branches, retired package names, or already
closed findings. Use them only when reconstructing why a decision was made.
