# M0 baseline, 2026-10-20

The eval and test numbers on `beta-mvp` at `b3fe8891`, before any harness change from the core build plan lands. Every later harness or memory PR is compared against these (build plan, T-8).

Environment: macOS, Node 22.23.2, pnpm 10.34.4, `pnpm install --frozen-lockfile`. Runs from `packages/runtime`.

## What was measured

### Scripted-model scenario suite

```
pnpm exec vitest run --config vitest.scenarios.config.ts
```

24 test files, 194 tests, all pass. This suite runs on every PR in `verify.yml` ("Runtime scenarios"). It also contains the nightly eval's own unit tests (`test/nightly-eval-*.test.ts`).

### Nightly eval, recorded mode

```
WALDO_EVAL_MODE=recorded WALDO_EVAL_OUT=scorecard.json pnpm eval:nightly
```

Runs in about 2 s with no keys and no network. In recorded mode the model answers with fixed text and nothing is graded, so the card shows whether every scenario runs, not how well Waldo answers.

| Measure | Value |
| --- | --- |
| Scenarios | 22 (context 8, follow-through 7, judgment 7) |
| Trials per scenario | 3 |
| Ungraded (ran, no grade in recorded mode) | 19 |
| Blocked | 3: `t11-packing-list-file`, `t17-photo-opinion`, `t18-voice-note` |
| Harness errors | 0 |
| Incomplete (budget stop) | 0 |
| Candidate calls | 93 (budget 10,000, not exhausted) |
| Candidate tokens | 1,860 (scripted gateway) |
| Judge calls | 0 |
| Pass rate, pass^k rate | none (nothing graded) |

The recorded CI gate (`evals.yml`, thresholds in `packages/runtime/evals/nightly/gate.ts`) holds a PR to this card: at least 22 scenarios, at most 3 blocked, no harness errors, nothing incomplete.

### Memory golden test

```
pnpm exec vitest run test/memory-golden-eval.test.ts
```

1 file, 1 test, passes.
